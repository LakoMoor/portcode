    First run#

    Five minutes from install to your first task.

    1. Open a folder#

    Run portcode in the folder you want to work in. For a port, that is the folder that holds the program to port: put the original in original/.

    The first time PortCode starts in a folder it opens the guided start (the same screen as /create) with a welcome. If the folder holds a game or a program (a .app, an .exe, a Unity game, a native executable), PortCode finds it and fills in the path for you; ← → on the path field switches between the finds. Press esc there to open the normal interface; it does not come back for that folder. Set PORTCODE_NO_WELCOME=1 to turn it off everywhere.

    When the prompt is empty, PortCode looks at the folder and puts a guess at your first message in the prompt box as grey text. Press tab to use it, esc to dismiss it, or just type something else. See A tour of the app.

    2. Pick a model and give it a key#

    PortCode speaks the OpenAI chat protocol, so almost any server works. Choose one way:

    • Any OpenAI-compatible server, step by step. Type /connect. Choose where it runs (Ollama, LM Studio, llama.cpp, vLLM, SGLang, OpenRouter, DeepSeek, OpenAI or your own), paste the address and key, press enter on the key to test it, pick a model from the list the server reports, and ctrl+s saves and switches to it. The address goes to providers.json in your config folder and the key to auth.json (mode 600), never into the project.
    • A local model, no key. Start Ollama, LM Studio, llama.cpp or vLLM, then type /provider ollama qwen3:14b.
    • Your Claude or ChatGPT subscription. Install Claude Code or Codex, sign in there once, then /provider claude-code sonnet or /provider codex default. No key and no API bill. See Claude Code and Codex.
    • A hosted API. Type /key and paste the key. It is hidden while you type and saved in your config folder with mode 600. From a shell: portcode auth set <provider>, or portcode auth set <provider> --from-env NAME to read it from an environment variable.
    TypeWhat it does
    /connect [provider]add or edit an OpenAI-compatible server in a form, with a connection test
    /providerlists providers and shows which still need a key
    /provider <name> [model]switches provider and model
    /key [provider]asks for the API key, hidden
    /modelslists the models the current provider serves
    /model <provider>/<model>picks a model
    /setupprints these steps again

    The model you choose is remembered for the next start. -m and PORTCODE_MODEL still win.

    3. Check that it works#

    portcode doctor

    To test the model itself (chat, tool calls, valid JSON, edits) run portcode eval.

    4. Start working#

    Type a task, or type /create. /create asks what you want to recreate (a website, a program, a game, a file format or nothing yet), how closely PortCode may look inside the original, and what to build it with. Then it starts the right agent in the right mode.

    Port this CLI to Rust, following rustport

    PortCode pins the original's sha256, records what it learns, and calls a module done only after parity passes. The details are in The port workflow.

    Settings worth knowing early#

    SettingDefaultWhat it does
    esc twicecancels the running request
    /yolooffapproves every permission request without asking, see Permissions
    "venv"onlets the agent create and use a Python .venv, see Python environments
    "team"offadds the team agent, see Team mode
    "suggest"onthe grey first-message suggestion
