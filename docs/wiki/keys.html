    Wiki / Use

    Keyboard shortcuts#

    In the prompt#

    KeysAction
    entersend
    alt+enternew line
    tabuse the start-up suggestion, or complete a / command, or switch to the next agent
    shift+tabswitch to the previous agent
    ↑ / ↓walk the prompt history (or move in the / menu)
    ctrl+a / ctrl+e (or home / end)start / end of the line
    ctrl+udelete from the cursor to the start of the line
    ctrl+wdelete the word before the cursor
    ctrl+cclear the prompt if it has text, otherwise quit
    ctrl+dquit when the prompt is empty
    escdismiss the suggestion, close a menu, or scroll back to the bottom

    While a request runs#

    KeysAction
    esc esccancel the request (the footer says press esc again after the first)
    ctrl+ccancel the request at once

    View#

    KeysAction
    ctrl+tshow or hide the model's reasoning
    ctrl+bshow or hide the sidebar
    pgup / pgdnscroll the transcript
    mouse wheelscroll the transcript

    Permission dialog#

    KeyReply
    y or enterallow once
    aalways allow that exact request for the rest of the session
    n or escreject

    Session list (--resume, /resume)#

    KeyAction
    ↑ ↓ or k jmove
    pgup pgdn home endjump
    enteropen the session
    esc or qleave without opening one

    Workbench (/workbench)#

    KeyAction
    j / kmove in the function list
    1 2 3Pseudo-C, disassembly, hex
    /filter functions
    aask the agent about the selected function
    escclear the filter, then close
    PreviousSlash commandsNextSessions and history
